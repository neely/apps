# apps

A collection of small, single-file static HTML apps, live at [apps.benneely.com](https://apps.benneely.com). No build step, no framework — each one is self-contained and can be opened directly or hosted as-is. Most follow a no-backend, browser-native approach (local state, sometimes a GitHub-backed sync layer).

## 1·3·5 Today (`135-todo.html`)

A daily todo list built around the "1 big thing, 3 medium things, 5 small things" planning method.

## Queue — Media Tracker (`media-tracker.html` / `queue.html`)

A tracker for movies, shows, books, or whatever media queue you're working through.

## Mobility Flow (`mobility-flow.html`)

A guided mobility/stretching flow — likely tap-through or timed sequence style.

## Soft Top Buyer's Guide — Charleston SC (`soft-top-guide.html`)

Reference guide for evaluating soft-top convertibles/Jeeps in the Charleston, SC area.

## Strikemap (`strikemap.html` / `strikemap-desktop.html`)

A map-based tool, with separate mobile and desktop layouts.

## Tilt Maze (`tilt-maze.html`)

A maze game controlled by device tilt (accelerometer).

---

Icons live in `icons/`. `testing/` holds work-in-progress builds not yet promoted to the root.
